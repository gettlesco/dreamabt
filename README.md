# dreamabt

Dream About Me — [dreamabt.me](https://dreamabt.me)

Nightly ritual. One dream of your own, and whatever someone sends you that night. Accounts use a first name plus a 3-emoji private key.

## Local

```bash
pnpm install
pnpm dev
```

http://localhost:3001

Copy `.env.example` to `.env.local` after the Supabase project exists.

## Supabase

New project only. Run `supabase/dream-about-me.sql`. Disable email confirmation.
